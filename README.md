# Copiloto Personalizado com IA para Desenvolvimento de Software

Projeto desenvolvido como atividade final do curso **Inteligência Artificial Aplicada ao Desenvolvimento de Software** da DIO.

---

## Sobre

Conjunto de prompts organizados em diferentes modos de uso de IA como copiloto de desenvolvimento, adaptados para um contexto de aprendizado em programação.

---

## Modos

| Modo        | Função |
|------------|--------|
| ASK        | Tirar dúvidas e explicar problemas |
| PLAN       | Estruturar soluções antes de implementar |
| EDIT       | Modificar código existente |
| STUDY      | Apoiar o aprendizado de conceitos |
| AGENT CODE | Implementar código a partir de requisitos |

---

## Stack utilizada

- JavaScript (Node.js)
- ESM (import/export)
- Express (quando aplicável)

Ferramentas como testes, lint e formatação são consideradas opcionais.

---

## Características

- respostas diretas e objetivas  
- foco em clareza e legibilidade  
- abordagem progressiva (do simples ao mais complexo)  
- suporte tanto para estudo quanto para prática  
- consistência entre os diferentes modos  

---

## Estrutura

Cada modo possui:

- regras de comportamento  
- formato de resposta definido  
- limites de atuação (ex: planejar, explicar, editar, implementar)  

---

## Observações

Os prompts foram ajustados para funcionar de forma mais alinhada com um ambiente de aprendizado em desenvolvimento backend com Node.js.
